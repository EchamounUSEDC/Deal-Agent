The IC Analyst

A virtual investment-committee analyst. Drop a deal in, and it scores the opportunity against a fixed Go/No-Go rubric, stress-tests the downside, and returns a committee-ready report — deterministic math, no guesswork, no fabricated numbers.

B

What happens to a deal

01

Drop

A pro forma lands in deals/inbox/. Any layout — the engine reads by label, not cell position.

02

Score

Metrics are mapped by synonym, run through the rubric, and stress-tested. Missing inputs fail their gate — never invented.

03

Report

A formatted workbook is written to deals/reports/; the input moves to deals/processed/.

04

Brief

The verdict, score, the gates that drove it, and the stress result are summarized for the committee.

F

Reading the verdict

GO Score ≥ 70 and no veto — clears the committee's bar.
CONDITIONAL GO Score 50 – 69.9 — workable, but flagged gates need a closer look.
NO-GO Score < 50, or any veto fired — pass.

Automatic vetoes

Any one forces NO-GO, whatever the total.

  • Storage: IRR ≤ exit cap · yield < 6.5% · population < 200k
  • Factory fund: LP IRR ≤ 8% pref · MOIC < 1.5×
  • A missing critical input counts as a fail — the engine never fills a gap with a guess.
Analysis to support the committee's decision — not investment advice. Every threshold is a named, editable constant; verdicts always show the input and the threshold each gate was measured against. IC Analyst · deterministic underwriting engine
